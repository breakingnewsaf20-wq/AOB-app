# Afghan Online Bazaar

Flutter marketplace foundation for `com.afghanonlinebazaar.app`.

## Included
- Firebase Authentication: email/password foundation
- Firestore product, user, seller, order models/services
- Customer cart/favorites foundation
- Seller dashboard/product creation foundation
- Admin dashboard foundation
- Order status model
- Validation and clear error messages
- FCM initialization foundation
- Firestore security rules

## Important
This is a development foundation, not a fully deployed marketplace. Phone OTP, production image hosting, payment/delivery integrations, AI backend, signing and Play Store release still need their real provider configuration.

## Run
1. Install Flutter.
2. Run `flutter pub get`.
3. The provided `android/app/google-services.json` must be present.
4. Run `flutter run`.

The Android application id is `com.afghanonlinebazaar.app`.
